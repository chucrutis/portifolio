# Portfólio Pessoal (HTML + CSS puros)

Projeto para a atividade prática:
- HTML5 semântico e CSS3 (sem Bootstrap, sem frameworks).
- 4 páginas: **Sobre mim (index.html)**, **Formação (formacao.html)**, **Portfólio (portfolio.html)**, **Contato (contato.html)**.
- Menu visível em todas as páginas (responsivo sem JavaScript).
- Formulário de contato apenas visual.
- Comentários explicativos no código.
